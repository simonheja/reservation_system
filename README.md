## Library Reservation Tool

This tool was made with reservations for spaces in libraries in made, more specifically for students during exam season.
The tool allows for reservations to be made at the location of your choice and shows all reservable spots that the chosen location has.
It shows a floorplan of the location (if available) and shows all possible locations, the seats have different colors depending on the availablity of the chosen time frame.
